# Routes

The project is a static, single-page landing site with no router.

| URL | Entry | Layout | Purpose |
|---|---|---|---|
| `/` | `index.html` | Inline sticky header + main + footer | WhatsCart marketing and conversion page |

## In-page anchors

| Anchor | Section |
|---|---|
| `#top` | Hero |
| `#features` | Product capability grid |
| `#how-it-works` | Four-step onboarding story |
| `#pricing` | Launch pricing |

All conversion links currently point to `https://app.whatscart.in/`.
